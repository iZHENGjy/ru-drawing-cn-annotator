# Prompt · Step 5 — answer the coverage-audit packets (answers/audit/pNN.json)

> 给复核员(人或 LLM agent)。每人分若干页。**错译比漏译更危险**:数字、钢筋直径、型号、件号、
> 标高必须与图上一字不差。

## 输入(工作目录 `<WORK>`)
- `packets/pNN.md`:候选清单。
  - `#k [未覆盖]` / `#k [空映射]`:疑似漏译。附识别文字(可能有错字)、红框坐标、邻近文字及其已有译文(`→` 后)。
  - `#k [放置失败]`:已有译文但没地方放,act 填 ok 即可(版面另行处理)。
  - `Ck`(续行核对):紧挨一条已译行的俄文,判断其意思是否已包含在该行中文里。纯文字判断,不必看图。
- `packets/pNN_sK.png`:候选裁图联排,左上红字 #k,红框圈出待查文字。**#k 必须看图核实**,识别文字仅供参考。
- 术语:`glossary/gost_general.json` + 本项目术语表(同一俄文全册一个译法)。

## 判定(act)
- `tr`:确实需要中文。给 `zh`(简洁的图纸用语,只译红框这一处)和 `ru`(你从图上读到的原文)。
  - 一个短语拆成多行且都没译:在最上面那行给整句译文,其余行 `ok`,why 写「并入#k」。
  - 例:«условно не показана» → 按简化画法未示出;«для Рм2.2» → 用于横梁 Рм2.2;«См. Бм2.5» → 见梁 Бм2.5。
  - 构件代号、件号、钢号、标准号原样写进中文。中文里出现的数字必须都能在 `ru` 里找到(`31_apply_audit.py` 会拒收)。
- `ok`:已被覆盖(邻近中文已含此意、表头被拆成多行而上一行已整体译出等)。why 必填。
- `skip`:不需要译:人名、设计院 logo、文件名/图号、纯英文行(旁边俄文已译)、把图形误识成的乱码、单个字母、轴号。why 必填。

拿不准时宁可 `tr`,但不得编造:看不清写「[?]」并在 why 说明。

## 输出 `answers/audit/pNN.json`
```json
{"items": [
  {"ref": "#1", "act": "tr", "ru": "Арматура Пм2 условно не показана", "zh": "板 Пм2 钢筋按简化画法未示出"},
  {"ref": "#2", "act": "ok", "why": "并入#1"},
  {"ref": "#5", "act": "skip", "why": "人名"},
  {"ref": "C3", "act": "ok", "why": "上一行已译「总用量」"}
]}
```
清单里每个 ref 都要有一条记录。只读 md 和联排 png;不要读整页大图,不要改其他文件。
完成后只回复一行:各页 tr/ok/skip 计数。
