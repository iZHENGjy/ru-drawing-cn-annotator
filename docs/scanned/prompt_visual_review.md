# Prompt · Step 6 — page-by-page visual review of the finished PDF (visual/rN/pNN.json)

> 给逐页看图复核员。图上**黑色是原图**,**蓝色是已加的中文**。任务:逐块看图,找出**还没有中文的俄文**
> 和**看不清的中文**。不要放过,也不要报不需要的。

## 输入
- `<WORK>/visual/r<N>/pNN_tK.png`:该页分块(K 按行从左到右、从上到下,相邻块重叠 5%)。
  每页全部分块都要看。为节省,**每轮同时读 3–4 张图**。

## 要报的问题(type)
1. `漏译`:一处俄文(词、表头、标注、说明、图名、注释、图签栏目、印章)附近**没有对应的蓝色中文**。
   中文可以在下方、右侧、细蓝线引出,或在右侧加宽栏/附近空白处的整块译文里——看到对应中文就算有。
2. `英文无中文`:只有英文、没有对应俄文的段落或标注,旁边也没有中文(俄英对照时英文那行不用单独译)。
3. `遮挡`:蓝色中文压在线条或文字上看不清,或字小到看不清。
4. `错译`:中文明显错,尤其数字或代号与原文不一致、或中文挂在了别的标注旁。

## 不用报
人名、设计院 logo、图号/文件名、ГОСТ/СП 编号本身、钢号、单独的构件代号、件号数字、轴号、尺寸数字、单位。
以下是规定写法,不算问题:
- 图签和左侧竖栏的标准栏目(编制、校核、签字、日期、替代存档号……)统一放在图签附近的蓝色「图签译文:…」
  对照行里(放不下时在页面右侧加宽栏),格内不逐个标。
- 「шт./pcs.N」统一标「根」(或项目设定的「件」),「ш./sp.N」统一标「间距」,不带数字;对照行开头有缩写说明。

## 输出 `visual/r<N>/pNN.json`
```json
{"checked": ["t1", "t2", "t3", "t4"],
 "issues": [
  {"tile": "t2", "type": "漏译", "text": "условно не показана", "where": [0.42, 0.31, 0.55, 0.34], "zh": "按简化画法未示出"},
  {"tile": "t3", "type": "遮挡", "text": "根", "where": [0.10, 0.80, 0.13, 0.82], "zh": ""}
 ]}
```
- `where`:问题原文在**该分块图内**的 0–1 比例框(尽量框准俄文/英文那一处;程序会再吸附到 OCR 框)。
- `text`:从图上读到的原文,数字照抄;`zh`:建议译文(遮挡类可空)。
- 没问题的页也要写文件(issues 为空),`checked` 必须列出全部分块。
不要改其他文件。完成后只回复一行:各页问题数。
